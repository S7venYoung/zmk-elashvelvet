# 左手 RESET 显示重置时刻

Nano 左手额度主题显示电脑本地时区的具体重置时刻，例如 RESET 19:20，不再显示剩余 02:35。复用现有 primaryResetAt 数据，不改变额度采集或 Cube 的 CODEX3 时间路径。

18 字节 host_metrics 数据长度和字段位置不变。reset 的 LE32 字段最高位为 1 时，低 31 位表示本地午夜起的分钟数（0–1439）。固件不递减此值，数据过期仍按原 90 秒规则隐藏。最高位为 0 的旧倒计时保留传输兼容，但新左手界面显示 --:--，不将其误当时刻。RESET 原倒计时进度条移除。

需要更新电脑配套软件、Nano 接收器和左手固件；右手系统信息无需为此重刷。旧版电脑软件不能提供新格式时刻，旧版左手固件不能正确解读新格式。普通按键、配对和 BL 不变，不需要刷 reset。本改动不宣称修复此前左手白屏或无法连接的问题。

C 协议/渲染测试覆盖时刻不递减、午夜、非法分钟和过期隐藏；Swift 编码主机测试覆盖 UTC+8 19:20、跨午夜及负时区。未自动运行 Actions 或构建固件。
