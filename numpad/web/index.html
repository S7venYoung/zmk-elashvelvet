01 首次安装

首次 SWD，此后网页升级

网页需要配套的 Eyelash WebDFU 启动程序。首次通过 SWD 刷入启动程序和 ZMK，之后使用本页面更新应用。

  1. 首次安装新版 WebDFU 合并 HEX。
  2. 关闭小键盘，按住物理 7＋9 再开机。
  3. 点击右侧连接，选择 Eyelash_WebDFU。
  4. 确认固件，点击开始刷写，保持供电与蓝牙连接。
WebDFU 启动程序源码已适配，尚未构建及实机验证。之前 4518738 的首次刷入 HEX 是旧启动程序，不支持本网页；请暂缓刷入，等待新版合并 HEX。
为什么旧启动程序不能连接？

标准 Nordic Legacy DFU 服务被 Web Bluetooth 屏蔽。新版使用小键盘专用 GATT 服务，保留 Legacy 传输协议；它不是 Secure DFU，不提供固件签名验证。普通手机 DFU 工具默认也不会识别这个专用服务。
