# 16Pad 双模使用指南

固件适用于带 16 颗 RGB 灯的 nRF52840 Pad。灯效版提交 `866f5e0` 已通过 Actions。用户已确认 Pad 能在 Dongle 模式连接 Nano。独立模式有 BLE 连接失败反馈，原因仍待定位。

## 下载与刷机

从[灯效版 Actions 的 Artifacts](https://github.com/S7venYoung/zmk-elashvelvet/actions/runs/44258798459) 下载并解压对应固件。让目标设备进入 UF2 启动盘，再拖入对应文件。

| 用途 | 压缩包 | 刷入文件 |
|---|---|---|
| 首次安装或更新 16Pad | `pad52840-dual-firmware` | `pad52840_dual.uf2` |
| 原 nRF52833 Nano 首次加入 Pad 支持 | `pad-dual-shared-nano` | `velvet_nano_dongle.uf2` |
| Pad 回退到原独立版 | `pad52840-dual-firmware` | `pad52840_standalone_recovery.uf2` |

普通更新无需刷 reset。Nano 已支持第三个外设时，仅更新 Pad 即可使用新灯效。左右手沿用现有固件。

## 模式切换与 DYA

先按住**第 4 排第 1 键（左下角）**，再按住**第 3 排第 3 键**至少 2 秒，然后都松开。两种模式均在 Pad 本地识别这两个实体位置。如果左下角改成了小键盘除号，就按 `KP/`＋`KP3`。Pad 重启后进入另一模式，分别保存两套模式的配对记录。

| 模式 | DYA 连接对象 | 键位配置 |
|---|---|---|
| 独立 | USB 连接 Pad，选择 `Pad16` | 改 Pad 自己的键位和功能层 |
| Dongle | USB 连接 Nano，选择 `Velvet46` | 改接收器键位图中追加的 16 个 Pad 键 |

Dongle 模式下，Pad 自己插 USB 时还会显示 `Pad16 Dongle`，这是 Pad 本地的 Studio 串口。

## 矩阵灯效

两套镜像都提供原有 4 种效果和 23 种 QMK RGB Matrix 效果。[完整效果列表](rgb/README.md)

独立模式使用 DYA 中保存的功能层绑定。如果将 `LT 1 KP8` 设在数字 8、将 `Underglow Next Effect` 设在层 1 的第二排第四键，就长按 8 再点该键切换灯效。

Dongle 模式使用固定实体组合。按住**左下角**，再点下表中的键。Nano 的 DYA 行为列表里无需添加灯效行为。

| 再点哪个键 | 操作 |
|---|---|
| 第 2 排第 3 键 | 灯光开关 |
| 第 2 排第 4 键 | 下一个灯效，可连续点按 |
| 第 3 排第 1 键 / 第 2 键 | 提高 / 降低亮度 |
| 第 3 排第 4 键 | 松开组合后进入 Pad 启动器 |

## Flash 分区

| 区域 | 地址 | 用途 |
| --- | --- | --- |
| MBR / S140 | 0x00000–0x26fff | 保留原设备内容 |
| 选择器 | 0x27000–0x27fff | Rasi BL 应用入口；含镜像 CRC 描述表 |
| A 镜像 | 0x28000–0x83fff | 独立模式，368 KiB |
| B 镜像 | 0x84000–0xd7fff | Dongle 外设，336 KiB |
| B 设置 | 0xd8000–0xdffff | 独立 NVS，32 KiB |
| BL 更新暂存 | 0xe0000–0xe9fff | 保留 |
| BL 短插拔日志 | 0xea000–0xeafff | 保留 |
| 共用模式日志 | 0xeb000–0xebfff | 模式与反码，忽略不完整记录 |
| A 设置 | 0xec000–0xf3fff | 保留原独立固件 NVS，32 KiB |
| BL 及其设置 | 0xf4000–0xfffff | 保留 |

不使用 0x1000 作为应用入口：这块 Pad 的 S140 7.3.0 与已验证 Rasi BL 要求应用从 0x27000 开始。选择器先检查镜像向量与 CRC；选中镜像无效时尝试另一套，两套均无效则请求进入原 BL。

## 共用 Nano

Nano 的 BLE 外设容量从 2 增加为 3；键位从原 61 个追加 Pad 的 16 个，原键位编号和前三层默认绑定保持不变，新增第 4 层供 Pad Fn 使用。左右手固件不在本次构建目标内，设计上无需更新，兼容性仍需实机验证。

保留现有配对，不刷 reset。首次接入 Pad 时需保留原左右手配对，让 Pad 使用新增连接位置。DYA 中已有的自定义键位属于设备存储内容，刷前应导出备份；源代码保留测试不等于设备自定义配置迁移已验证。

Dongle 模式的 Pad USB 保留 Studio 自定义 RPC、进入 BL 和诊断通道；键位应通过连接 Nano 的 DYA 配置。独立模式通过连接 Pad 配置。

## 构建与刷入

工作流仅支持手动触发，需用户确认后构建：两套 Pad 镜像、选择器与增加第三连接的 Nano。CI 检查真实镜像大小、地址、向量、CRC 和 Nano 链接内存；本机仅运行主机测试，不编译 Zephyr 固件。

最终文件：

- `pad52840_dual.uf2`：选择器与两套镜像的完整应用包，只给 Pad 使用。
- `velvet_nano_dongle.uf2`：配套共用 Nano 接收器固件，只给原 Nano 使用。
- `pad52840_standalone_recovery.uf2`：原 `c6714bd` Actions 产物的单镜像回退文件。

**不要刷 `internal-*-DO-NOT-FLASH` 中的单独镜像。** 安装双镜像不更新 BL、不包含 S140、设置或 reset。现有断电短插拔进入 BL 的方式保持不变。首次安装且无有效模式日志时默认独立模式；后续更新沿用最后模式。

回退 Pad 时只刷提供的独立回退文件，通常无需 reset。回退文件从原 0x27000 入口启动，不再使用双镜像选择器和模式日志。Nano 如需回退，使用原先已验证的接收器固件。

主机检查覆盖模式日志、镜像 CRC、快捷键时序、打包范围和原 61 个键位的保留。左右手与 Pad 三台并发输入、矩阵动画方向仍待实机核对。
