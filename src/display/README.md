# Cube 右手系统信息主题

右手固定使用 Nano 分支的系统信息页：CPU 使用率、RAM 使用率、CPU 温度；不显示时间、天气、RAM 容量。沿用反色、修正后的蓝牙图标、真实输出状态与 BLE 1–5 卡槽。上电直接显示系统页，不经过猫咪主题。左手固定显示 Nano 的猫咪主题（自身电量、连接状态、主控同步的层号）；Cube 发现服务保持原样。

数据由 Cube central 通过原生 ZMK split relay 发送，不能由右手自行读取电脑指标。`vldash` 为 22 字节：版本 2、主题 0/1（右手忽略此字段，固定系统页）、输出 0/1/2（无/USB/BLE）、BLE 卡槽 1–5（其他输出为 0），随后是与 Nano 完全一致的 18 字节 host_metrics。每秒发送一次，超过 3 秒未收到数据时隐藏旧数值，显示 `--`，不填充示例值。主控应使用与 Nano 一样的 90 秒电脑数据过期处理。

层号使用 `vlcat` 两字节消息（版本 1、零起始层号），显示加一；5 秒超时显示 L--。右手每两秒返回 `vldack` 诊断心跳。所有 relay 名称容量为 32 字节。

Cube 主控的 codex/xingzhi-cube-dongle 已实现上述发送协议；配套软件 main 已补齐 Cube USB/Wi-Fi 的 HOST1 数据发送，复用原有采集器。需更新主控、配套软件和本分支键盘固件。没有收到有效主控数据时，屏幕仍显示系统页框架和右手电量/连接状态，电脑输出状态、层号、CPU/RAM/温度显示未知。

固件：左手 velvet_left_cube.uf2，右手 velvet_right_cube.uf2。普通升级无需 reset 或更新 BL；只在用户明确触发 Actions 后构建。
